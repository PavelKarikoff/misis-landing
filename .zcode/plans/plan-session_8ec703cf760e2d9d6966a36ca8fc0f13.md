# Переработка linguastudies.misis.ru в современный лендинг кафедры ИЯКТ

## Что выяснено при исследовании

**Текущий сайт** — WordPress + Elementor: перегруженная главная, формы заявок спрятаны в попапах, устаревшая вёрстка. Контент: курсы ДПО (с датами старта и часами), программы ВО, олимпиады для школьников («Код открытий», «Искусство учить», «Иностранные языки для глобального прогресса», кейс-чемпионат CUP MISIS Case), конференции, контакты (english@misis.ru, +7 916 927-73-05).

**Фирменный стиль МИСИС** (снял вычисленные стили прямо с misis.ru через браузер):
- Основной цвет — глубокий тёмно-синий **#0A1E64**
- Акцент — электрик-синий **#0541F0** (кнопки CTA, ссылки)
- Дополнительные: жёлтый #FFD110, голубой #69BBEB, зелёный #B7E7A0, светлые подложки #F1F2FE / #F9F9FF
- Шрифты МИСИС: **Nekst** (заголовки) + **Raleway** (текст)

## Что делаем

Одностраничный адаптивный лендинг в `/Users/pavelkoff/Desktop/MISIS/` — статичный HTML/CSS/JS без сборки (легко залить на любой хостинг).

### Структура страницы
1. **Шапка** (sticky): название кафедры, якорная навигация, кнопка «Оставить заявку», мобильное бургер-меню
2. **Hero**: крупный заголовок, подзаголовок, CTA-кнопка, фирменный фон (SVG-паттерн)
3. **Направления** — 3 карточки: Дополнительное образование / Высшее образование / Школьникам и студентам
4. **Курсы ДПО** (ядро): карточки всех курсов из каталога (языки: английский, испанский, немецкий, французский; «ИИ в преподавании иностранных языков»; «Локализация видеоигр»; «Подготовка к ЕГЭ»; «English for Academics»; «Педпроектирование в цифровой среде» и др.) с часами, стартом, фильтрами по аудитории и кнопкой «Записаться» — она открывает форму с предвыбранным курсом
5. **Программы ВО**: бакалавриат/магистратура со ссылками на официальные страницы misis.ru
6. **Проекты**: олимпиады для школьников, проекты для студентов, конференции
7. **О кафедре**: краткое описание + преимущества (преподаватели МИСИС, удостоверение о ДПО, гибкий формат)
8. **FAQ**: аккордеон с типовыми вопросами (документы, оплата, формат, сроки)
9. **Форма заявки + контакты**: имя, телефон, email, выбор курса, комментарий, согласие на обработку персональных данных
10. **Подвал**: контакты, VK/Telegram, ссылки на misis.ru

### Технические детали
- `index.html`, `css/styles.css`, `js/main.js`, `assets/` (SVG-логотип, favicon), `README.md`
- CSS-переменные под фирменную палитру, mobile-first адаптив, плавные анимации появления, доступность (семантика, контраст, фокус)
- JS: мобильное меню, scroll-spy, фильтрация курсов, аккордеон FAQ, валидация формы (маска телефона, email)
- **Заявки — демо-режим**: валидация → сохранение в localStorage → сообщение об успехе. Функция отправки изолирована в одну точку (`submitLead`), чтобы потом за один шаг подключить email-сервис, Telegram или Битрикс24. Инструкция — в README.
- Визуал — векторная графика в стиле МИСИС (пиктограммы, паттерны), без стоковых фото; места под фото кафедры помечу
