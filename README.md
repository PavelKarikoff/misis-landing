# Лендинг кафедры ИЯКТ НИТУ «МИСИС»

Современный одностраничный сайт (лендинг) для кафедры иностранных языков и коммуникативных технологий — переработка lingua studies (linguastudies.misis.ru). Информация о программах + заявка на обучение.

## Структура проекта

```
MISIS/
├── index.html          — вся страница (одна, якорная навигация)
├── css/styles.css      — стили: фирменная палитра МИСИС, адаптив, анимации
├── js/main.js          — меню, фильтры, FAQ, форма заявки
├── assets/
│   └── favicon.svg     — иконка сайта
│   └── fonts/          — сюда положить лицензионный шрифт Nekst (см. ниже)
└── README.md
```

Никаких сборщиков и зависимостей — чистые HTML/CSS/JS.

## Как открыть локально

Достаточно открыть `index.html` двойным кликом, но для корректной работы шрифтов Google лучше поднять локальный сервер:

```bash
cd MISIS
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Фирменный стиль

Палитра снята с misis.ru и зашита в CSS-переменные в начале `css/styles.css`:

| Цвет | Код | Использование |
|---|---|---|
| Тёмно-синий | `#0A1E64` | основной фон hero/заявки, текст |
| Электрик-синий | `#0541F0` | кнопки CTA, ссылки, акценты |
| Жёлтый | `#FFD110` | акценты на тёмном фоне |
| Голубой | `#69BBEB` | декоративные элементы |
| Зелёный | `#B7E7A0` | теги, иконка успеха |
| Лавандовый | `#CED8FC` | теги, декор |
| Светлая подложка | `#F1F2FE` / `#F9F9FF` | фоны секций |

**Шрифты.** Текст — Raleway (Google Fonts, открытая лицензия; также входит в фирменный стек misis.ru). Заголовки задуманы в фирменном шрифте **Nekst** — он коммерческий (Денис Серебряков / MyFonts). Если у университета есть лицензия:

1. Положите файлы `Nekst-Regular.woff2`, `Nekst-Bold.woff2`, `Nekst-Black.woff2` в `assets/fonts/`.
2. Раскомментируйте блок `@font-face` в начале `css/styles.css`.

Заголовки автоматически переключатся на Nekst (в CSS он уже первый в стеке `--font`).

## Заявки: демо-режим и подключение реальной отправки

Сейчас заявки **не отправляются**: форма валидируется, показывается экран успеха, а заявка сохраняется в `localStorage` браузера (ключ `misis_leads`) и выводится в консоль.

Вся отправка изолирована в одной функции `submitLead(payload)` в `js/main.js` (помечена комментарием «ТОЧКА ПОДКЛЮЧЕНИЯ РЕАЛЬНОЙ ОТПРАВКИ»). Примеры замены:

**Formspree / Web3Forms** (письма на email кафедры):
```js
function submitLead(payload) {
  return fetch("https://formspree.io/f/ВАШ_ID", {
    method: "POST",
    headers: { "Content-Type": "application/json", Accept: "application/json" },
    body: JSON.stringify(payload)
  });
}
```

**Telegram-бот** (заявки приходят в чат):
```js
function submitLead(payload) {
  var text = "Новая заявка!\n" + payload.name + "\n" + payload.phone +
             "\n" + payload.email + "\nКурс: " + payload.course;
  return fetch("https://api.telegram.org/bot<ТОКЕН>/sendMessage?chat_id=<CHAT_ID>&text=" +
               encodeURIComponent(text));
}
```

**Битрикс24** — рекомендую встроенную CRM-форму Б24 вместо самописной формы: вставьте её код в секцию `#contacts`, а логику `submitLead` оставьте как бэкап.

## Публикация

Статику можно выложить куда угодно:

- **На существующий хостинг WP** (linguastudies.misis.ru) — залить файлы по FTP/SSH в отдельную папку или заменить содержимое темы.
- **GitHub Pages / Netlify / Vercel** — подключить репозиторий, без настроек.

## Где править контент

- **Курсы** — секция `#courses` в `index.html` (карточки `.course-card`) + одноимённые `<option>` в форме (тексты должны совпадать — кнопка «Записаться» выбирает курс по названию).
- **Программы ВО** — секция `#degrees`.
- **Проекты** — секция `#projects`.
- **Вопросы FAQ** — секция `#faq` (элементы `<details>`).
- **Контакты** — секция `#contacts` и подвал.

## Проверено

- Десктоп и мобильные ширины (меню-бургер < 860px).
- Валидация формы: ФИО, телефон (маска +7), email, выбор курса, согласие на обработку данных.
- Доступность: skip-link, семантика, aria-атрибуты, видимый фокус, поддержка `prefers-reduced-motion`.
